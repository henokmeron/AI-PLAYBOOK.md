# Document Q&A benchmark v1 — 2026-10-14

Dataset: `eval/rag/datasets/v1` (11 synthetic documents, 40 labelled questions).
Scorer version 1.1. Answers were generated by the live Qwen3.5-27B through an **isolated**
gateway on port 8014 (`/tmp/ragdev`), which reused the running model on port 8002 read-only.
The live gateway on 8010 and the console on 8080 were not restarted and are still running
the code from before this change.

Retrieval metrics are deterministic and were computed locally with no GPU
(`eval/rag/results/retrieval-*.json`, `ablation-v1.json`).

## Retrieval (offline, top 8)

`retrieval-current.json` scores the new pipeline with the coverage gate off, which is how
`run_retrieval.py` calls `search()`. The shipped gateway uses `RAG_MIN_COVERAGE=0.15`.
The ablation shows that threshold does not change these ranking numbers; it only adds abstentions.

| Metric | Baseline `6ebab4d` | Current (gate off) | Gate 0.15 (ablation) |
| --- | ---: | ---: | ---: |
| recall@1 | 0.708 | 0.830 | 0.830 |
| recall@3 | 0.896 | 0.968 | 0.968 |
| recall@5 | 0.912 | 0.974 | 0.974 |
| MRR | 0.863 | 0.969 | 0.969 |
| precision@5 | 0.248 | 0.248 | 0.248 |
| doc recall of returned chunks | 0.984 | 1.000 | (same ranking) |
| unanswerable questions abstained by the gate | 0 / 8 | 0 / 8 | 2 / 8 (0.25) |
| answerable questions wrongly abstained | 0 | 0 | 0 |

Precision@5 stays low because most questions have one relevant chunk and the metric still
looks at five. Raising the gate to 0.25 starts abstaining on answerable questions
(false-abstain rate 0.031), so 0.15 is the shipped value.

| Run | Concurrency | Accuracy | False answers | Injection successes | Citation present | Latency p50 | Latency p95 |

| Baseline, concurrency 1 | 1 | 39/40 (0.975) | 0 | 0 | 1.000 | 2.49 s | 7.25 s |

| Current, concurrency 4 | 4 | 40/40 | 0 | 0 | 0.969 | 3.70 s | 8.57 s |

The baseline miss was q019, a multi-document question. Current mean prompt size was 2,583
tokens (max 4,140) and mean completion 164 tokens. The baseline run did not record token
counts. One of the 32 answerable answers did not use the `[Source N]` form the scorer
counts, so the citation rate is 0.969 even though every counted citation pointed at a real,
relevant source (`citation_valid_rate` 1.0).

Wall time for 40 questions: 139 s baseline at concurrency 1, 143 s current at concurrency 1,
86 s current at concurrency 4.

## Regression bar for the next run of this dataset

Fail the change if, against dataset v1: recall@3 drops below 0.90, MRR drops below 0.90,
an answerable question is abstained by the gate, an unanswerable question receives a
non-abstaining answer, an injection question succeeds, or the limits probe returns any 5xx.
These bars are for this 40-question set. They are not a claim about production accuracy.

## What this does not measure

Paraphrase and synonym questions (the audit calls this benchmark v2), human grading of
free-text answers, and a fresh Pod. Answer correctness here is an automatic check against
reference answers and forbidden strings, reviewed while the scorer was built, not a
separate human grading pass.
